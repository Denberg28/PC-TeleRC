# PC TeleRC v1.2.0rc4 — Native map planning

Plan missions directly in PC TeleRC. Click the map, or right-click a waypoint,
for Go Here, Hold here, Return to planned home, and Set planned home here.
Map actions edit the selected rover's offline draft. They never arm, start,
switch mode, or open a radio connection. Upload, readback verification, Arm,
and Mission start retain their separate deliberate controls.

- Go Here adds a normal waypoint; on an existing point it changes its type.
- Hold adds a waypoint followed by a relative 2–10 second stopped NAV_DELAY.
  The current firmware allows this range. This is an arrival pause, distinct
  from the existing live HOLD button, which requests HOLD immediately.
- Set planned home here places a blue H marker for this rover's route.
  It is user-selected planning metadata, never an inferred GPS or FC home.
- RTH adds a final normal waypoint at planned home. It does NOT invoke the
  flight controller's RTL mode or modify its home. The rover follows the
  preceding route and then this return leg. Review that leg for obstacles.
- Drag a waypoint to move it; drag a line to insert a point in the route.
  The draft commits once on release inside the map. Escape, lost button,
  viewport changes, rover switching and session changes cancel the edit.
- The final RTH point follows planned home and cannot be dragged separately.
  New points are inserted before it. Home, types and holds restore per rover.
- QGC WPL export preserves executable waypoints and hold delays. Re-imported
  WPL is a read-only draft and does not retain the blue planning-home marker
  or the semantic RTH label; the return waypoint remains in its original place.

The paused Mission Planner bridge is not enabled or required by this build.
No firmware or private pairing configuration changes. Fleet firmware remains
0.5.0rc1, PWM converter 1.0.5, with the pinned public firmware package.

This is a release candidate. Physical motor, radio, RC takeover and fleet
mission testing remain pending. Review routes made with versions before rc3:
those versions could save incorrect longitudes from map clicks.
