# PC TeleRC v0.1.2 — live camera desktop

Stable release with a central live camera, lower-left rover map, compact buttons, a collapsible settings panel and percentage sliders for steering, drive and throttle limit. Uses the exact TeleRC Android logo in the app and Windows executable/installer.

Camera sources: USB camera/capture device, RTSP/HTTP video and HTTP MJPEG. Network video uses the bundled Qt/FFmpeg backend. Video is independent of Wi-Fi/LoRa/ELRS control; LoRa itself does not carry video. Stalled/unavailable video is visibly identified.

Map and telemetry use real, fresh data from the locked autopilot. Online map tiles need internet; without them the GPS track remains available. No GPS means a waiting state. The map does not estimate position from driving commands.

Retains wheel and WASD/arrow keyboard driving, Space neutral brake priority, separate sensitivities, explicit ARM, manual enable/re-enable, neutral acquisition, source-session guards and stale-input/link stops. Settings edits disable control before application. Control-worker input remains independent of camera decoding and GUI display refresh.

Validation includes the full application regression suite, actual local HTTP H.264 and MJPEG decoding, focus/brake/staleness checks, small/normal UI layouts, packaged logo/backend checks and a frozen Windows executable media/UI test. All firmware host fault suites rerun. Unchanged target binaries are reused only after firmware source equality and SHA256 verification against the rc2 baseline.

The included firmware remains LilyGO 0.5.0 and the existing PWM converter. No reflash is necessary for the camera/UI change. Physical camera compatibility, motor braking, RF range and hardware fail-safe timing remain user bench/field validation items. Previous stable v0.1.1 and v0.1.0a10 remain available as rollbacks.
