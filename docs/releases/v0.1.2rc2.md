# PC TeleRC v0.1.2rc2 — sketch pairing, OLED sleep and relay nodes

LilyGO firmware 0.5.0 adds an editable eight-character LoRa password/frequency at the top of each sketch, 30-second OLED sleep with BOOT wake, and a standalone NODE relay sketch using the same password as BASE/ROVER. Non-empty sketch pairing overrides old NVS; empty retains saved/web pairing.

Use relay count 0 for direct, 1 for one NODE, 2 for two ordered NODEs. Node index 1 is nearest BASE; index 2 nearest ROVER. All boards must match frequency/key/count. BASE stays native USB-to-LoRa. ROVER preserves Wi-Fi/LoRa selection. A sleeping display does not stop the link; the first BOOT gesture wakes only.

Optimized forwarding avoids flooding, selects the freshest USB command just before TX and avoids a fixed long wait after valid replies. Existing 500 ms control watchdog, per-axis freshness, neutral acquisition, explicit ARM and receiver takeover are retained. PWM converter 1.0.5 remains unchanged. Hardware range and stop latency remain unverified.

Read LILYGO-SKETCH-RELAYS.md in the package. Firmware target ZIPs are grouped by BASE, ROVER, NODE and original ESP32 targets. Templates/prebuilt images have no preset LoRa password; compile edited sketches for a private password. Draft candidate; v0.1.1 remains stable Latest.
