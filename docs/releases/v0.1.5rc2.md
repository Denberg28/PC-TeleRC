# PC TeleRC 0.1.5rc2 — reviewed mission planning release candidate

Pairs with **TeleRC LoRa Mission 0.2.0rc1** BASE, ROVER and NODE sketches.

- Shorter mission UI, collapsible plan/output/help panels and persistent state.
- Ordered map waypoints and F1/F2/F3 ON/OFF events with stopped action windows.
- Recovery connection without a draft; disarmed upload, full readback, explicit RC
  arming and separate exact rover/digest confirmation for one-shot START.
- Version/route/permission handshake, heartbeat fairness, bounded telemetry batches,
  stale-source cancellation, verified HOLD, no automatic reconnect/start replay.
- Planning-only draft restoration; read-only route review remains available while connected.

The package includes the offline profile generator and updated source for every
radio role. Generate and flash a complete matching private set. No shared default
key or operational private key is distributed. Keep the existing stable/manual
installation as rollback; these mission sketches use a separate radio protocol.

This is a release candidate. See the recorded host, sanitizer, actual target and
UI checks in the evidence. Native Windows/frozen qualification and physical RC,
RF-loss, stopping-distance and independent accessory-cutoff checks remain required
before stable promotion. HOLD does not disarm or guarantee auxiliary OFF.
