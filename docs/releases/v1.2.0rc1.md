# PC TeleRC v1.2.0rc1 — map-only fleet missions

A central fleet map replaces the FPV cockpit. Each rover has its own Connect,
Arm, Mission start, Disarm and HOLD controls, with separate plans and live/stale
moving GPS labels. Video uses external FPV monitors.

Requires matching fleet BASE/ROVER 0.5.0rc1. Existing TU2 nodes and the PWM converter
1.0.5 remain compatible. The private upgrade bundle preserves existing keys.

One USB owner multiplexes isolated rover sessions. The BASE maintains per-rover
routes, queues and actual PC heartbeat forwarding, with measured radio admission,
fair polling and priority HOLD. One foreground transaction runs at a time while
other connected rovers remain monitored. IDs 1–20 are supported; simultaneous
capacity depends on measured airtime and topology and is not physically qualified.

Arming is explicit, stationary in HOLD, normal FC arming only. ARM/START/DISARM
are not retried after an unknown result. There is no auto-arm, automatic mission
replay or FC parameter writing. This is a development candidate; physical fleet,
RF, electrical, motor and RC takeover qualification remains pending. The app is unsigned.
