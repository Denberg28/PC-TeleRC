PC TeleRC v0.1.1 — stable release

Consolidates the Windows controller app with separate steering/throttle sensitivity, LilyGO T3-S3 firmware 0.3.1 for Wi-Fi or LoRa with link LED indication, and PWM converter 1.0.5 with the verified in-pulse noise fix. USB diagnostic waits are bounded across current board roles.

Downloads include the Windows installer and portable app, complete source, firmware sketches, six role-specific target builds and SHA256 checksums. The LilyGO rover defaults to Wi-Fi; ROVER_LORA is a separate build used with BASE. SpeedyBee remains in the control path. Flash the PWM converter for the glitch correction, then only the link-board roles installed on your rover.

Neutral acquisition, genuine-loss timeouts, explicit ARM/PC enable and transmitter takeover are retained. Read STABLE-v0.1.1.md and LILYGO-WIFI-LORA.md before flashing. No FC parameter changes are applied automatically.

Validation: application regression tests, 19 sanitized host firmware variants and six pinned ESP32 target builds, plus Windows packaging and required-download verification. Physical rover ground testing, RF range and electrical behavior remain outstanding. v0.1.0a10 remains available as the previous stable rollback.
