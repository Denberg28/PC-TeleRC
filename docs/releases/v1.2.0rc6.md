# PC TeleRC v1.2.0rc6 — Route export fix and waypoint workflow

Install the Windows application update or extract the portable ZIP and run
PC-TeleRC.exe. Fleet firmware 0.5.0rc1 and PWM converter 1.0.5 are unchanged.
Keep your private paired firmware. This remains a release candidate.

## Fixed export and import

The rc4/rc5 map menu could store an unused zero hold duration on normal Go here
waypoints. The rc5 native-plan validator rejected that field, so Export route
showed "Invalid map action" and created no file. Normal waypoints now use a
valid inactive duration. Loading or exporting affected older drafts repairs only
that unused field; coordinates, waypoint order, home and actual holds remain.
Invalid active hold durations are still rejected.

Export route suggests rover-NNN.telerc.json. Native plans reopen for editing and
preserve home, Hold/Return labels, output mappings and speed. WPL remains an
interchange option and imports read-only. A successful save shows the filename
and folder; failures show a clear message. The next file picker starts at the
last route file. Missing extensions and names containing dots are handled.

## Map and mission workflow

The map menu has a compact title, coordinates and concise actions. Hold on
arrival opens a small duration picker with clear Apply/Cancel controls. The
workflow reminder now includes Arm: Plan → Connect → Upload → Arm → Start.

Go here edits an offline waypoint. Hold on arrival pauses at that waypoint
before continuing. Return home appends a final normal waypoint at the explicit
planned home; it does not change FC home or activate RTL mode. Review every leg
for obstacles. Map edits and file operations never initiate rover movement.

Live fleet markers show reported heading where available, and rover cards show
reported speed. Invalid coordinates, invalid GPS fixes, stopped sessions and
expired GPS samples remain stale; their last valid position is retained. No
position interpolation or motion is fabricated between telemetry samples.

Upload and full readback verification, explicit normal Arm, one-shot Start,
HOLD, RC takeover and loss policies remain intact. The reviewed MAVLink fleet
simulation covers popup planning, addressed upload/arm/start, changing rover
positions, HOLD and isolation of a second rover. Physical radio, motor and
handset takeover validation remain pending.
