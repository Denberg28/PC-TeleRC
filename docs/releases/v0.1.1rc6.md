PC TeleRC v0.1.1rc6 adds separate steering and throttle sensitivity controls (25–100%, default 100%) to the Controller panel. Both settings persist independently. Existing settings keep their steering value and use 100% throttle sensitivity.

Throttle sensitivity scales forward and reverse before the existing throttle limit. Neutral checks use unscaled pedal input. Editing either control disables PC Control until settings are applied and control is manually enabled. Diagnostics show both gains and the throttle limit.

Retains rc5 Wi-Fi, SX1262 ArduRover/Direct, and ELRS workflows. No sketch update is required for this feature. Hardware validation is still required; v0.1.0a10 remains the stable baseline.
