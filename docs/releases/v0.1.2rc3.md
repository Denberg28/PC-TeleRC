# PC TeleRC v0.1.2rc3 — keyboard driving candidate

Adds an applied Wheel / Keyboard selector with WASD and arrow-key steering/drive. Space commands neutral with priority over all directions; releasing Space cannot resume a held direction until that key is released and pressed again. Existing steering/drive sensitivities and throttle limit apply.

Keyboard driving requires focus in its driving area. Focus loss, settings/source edits and stale input stop control; recovery requires manual enable with all keys released. Keyboard works without a joystick through the existing Wi-Fi, LoRa and experimental ELRS USB profiles. ARM remains separate. Wheel acquisition timestamps and the radio protocols remain unchanged.

See KEYBOARD.md in the portable package. No firmware upload is required for this application change. Physical braking remains dependent on the existing motor/FC configuration; neutral does not guarantee active braking.

Validation: full application regression, dedicated keyboard and Qt focus tests, source compilation, Windows PyInstaller build and Inno Setup installer. Hardware timing remains unverified. Draft test candidate; stable v0.1.1 and previous candidates remain available.
