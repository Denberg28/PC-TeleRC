# PC TeleRC v1.2.0rc5 — Editable plans and route recovery

Application-only release candidate based on v1.2.0rc4. Install the Windows
installer or extract the portable ZIP and run PC-TeleRC.exe. Existing rc4 users
need only the application update. Fleet firmware 0.5.0rc1 and PWM converter
1.0.5 remain byte-for-byte unchanged; keep your private paired sketches.

## Changes

- Undo/Redo for each rover's offline draft, including dragging, route actions,
  Clear, imports, output settings and speed. Ctrl+Z undoes; Ctrl+Y or Ctrl+Shift+Z
  redoes for the selected rover. Retains at most 50 edits per rover in memory.
  History is locked while connected or busy and resets when the app closes.
- Export route defaults to an editable TeleRC plan (.telerc.json). It preserves
  planned home, Hold/RTH labels, waypoint actions, F1–F3 output settings and
  speed. Import restores the draft for the selected rover, ready for editing.
  Incomplete drafts can be saved without becoming uploadable.
- QGC WPL import/export remains available. Imported WPL is read-only. WPL does
  not preserve the blue planned-home marker or semantic RTH label; its final
  ordinary return waypoint and hold commands remain executable.
- Route list refresh preserves selection and scrolling. Map position remains
  stable through Undo/Redo. Malformed native plans are rejected before changing
  any existing draft, output binding or speed. Imports cancel if the draft,
  selected rover or session changes while the file picker is open.

## Operation

Map actions, recovery and imports edit drafts only. Upload while disarmed and
perform full readback verification. Then deliberately Arm and Mission start.
Undo/import never restores verification, control authority or accessory-cutoff
consent. RTH remains a planned final waypoint, not the FC RTL mode or live home.
Review all route legs for obstacles. Keep RC takeover and independent cutoff.

## Verification boundary

Publication is gated on current Windows regressions, the exact frozen Windows
executable's map/recovery checks, unchanged pinned firmware, sanitation and
uploaded/downloaded asset checksums. The package includes the resulting evidence.
The eleven existing board-build records are reused for the unchanged firmware;
no new firmware compilation is claimed. Physical radio, motor, RC takeover and
multi-rover qualification remain pending. This is a release candidate.
