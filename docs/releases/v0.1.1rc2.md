# PC TeleRC v0.1.1rc2 — ELRS Reliability Test Candidate

ELRS USB stalls, delayed control checks and pending reconnect edits could previously leave the operator with an unclear or stale control state. This candidate separates safety checks from the 5 Hz radio command rate, stops failed USB sessions, and makes disconnect/reconnect explicit.

Based on the a10-derived v0.1.1rc1 radio dropdown candidate. Original Wi-Fi/LoRa protocols and normal control rates remain in place.

- 20 Hz ELRS safety checks, fresh heartbeat checks at ARM/enable, worker deadline latch and rover-only heartbeat lock.
- Bounded receive work and USB queues; no automatic port reopening or command catch-up bursts.
- Local output purge before owned neutral/release; monitor-only sessions do not write RC overrides.
- Serialized control transitions and disable-before-DISARM.
- Settings edits cancel delayed reconnect, old callback generations are rejected, and settings-save failures remain pending.
- USB-open and rover-connected states are distinct. Port refresh preserves explicit selection and supplies device-description tooltips.

Local validation: 99 tests passed, including the 76 existing candidate tests and 23 additional fault/workflow cases. Syntax checks and diff whitespace checks passed. Windows CI separately runs the full suite, builds PyInstaller portable output and the Inno Setup installer, and generates checksums before publishing this prerelease.

Tests cover USB stalls/removal, partial writes, malformed telemetry, excess receive backlog, newest-sample rate limiting, controller loss between send deadlines, fresh-input-after-suspend, stale heartbeat gates, neutral/release ordering, monitor-only disconnect, command serialization, pending-setting gates, failed saves and reconnect callback cancellation.

The HGLRC T ONE / GEPRC pair, RF delivery latency, physical stop time and RadioMaster Pocket takeover remain unverified. Follow [ELRS setup and bench acceptance](../ELRS.md). USB write completion is not vehicle delivery confirmation. This prerelease does not promote or replace stable v0.1.0a10.

Publication authorized by the user on 2026-10-14. GitHub assets are built by the repository Windows CI using PyInstaller and Inno Setup, separately from the earlier local bundled-runtime test package.
