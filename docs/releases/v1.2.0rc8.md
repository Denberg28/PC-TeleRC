# PC TeleRC v1.2.0rc8 — Compact dark fleet station

The fleet UI now uses charcoal panels, restrained teal accents and the compact,
minimal Segoe UI typography of the Aero layout. The narrower rover roster gives
more space to the map. Connection details, coordinates and output settings expand
on demand; route file controls, mission status and HOLD remain accessible.

The new app icon depicts a radio-connected wheeled rover. The header, Windows
executable, installer and shortcuts share its scalable source and seven ICO sizes.
Popups, snapshot tables, checkboxes, dropdowns and numeric-step controls are styled
for the dark palette. The Online tiles choice now persists between launches.

![Dark fleet station](https://github.com/Denberg28/PC-TeleRC/releases/download/v1.2.0rc8/DARK-UI.png)

## Features retained and reviewed

- Separate plans for Rover 1–20, shared BASE, per-rover Connect/Arm/Mission start/Disarm/HOLD.
- Native map actions, drag editing, planned home, 2–10 second arrival holds and final return waypoint.
- Editable TeleRC files, WPL interchange, per-rover Undo/Redo and draft recovery.
- Offline raster MBTiles/cache, live/stale addressed GPS, heading/speed and map fit/follow.
- Disarmed upload plus complete readback, exact rover/digest confirmation and one-shot start.
- Modeless read-only Load from FC, empty/home-only handling and session-isolated results.
- Explicit auxiliary-cutoff consent, FC policy/output checks and bounded USB/worker recovery.

The included FEATURE-REVIEW.md analyses every active operator feature and its
verification, fixes, limitations and legacy boundary. Earlier camera/manual
wheel/keyboard/Wi-Fi/ELRS features are historical source, not part of this
map-only fleet executable. FPV remains external.

## Install and compatibility

Use PC-TeleRC-Setup-v1.2.0rc8.exe or extract the portable ZIP and run PC-TeleRC.exe.
Installer identity and user data location are retained. Fleet firmware 0.5.0rc1,
PWM converter 1.0.5, private pairing and saved route formats are unchanged.
Correctly paired rc7 firmware needs no reflash. Public example images are RF-OFF;
private provisioned profiles, keys, configuration and binaries are not included.

The firmware ZIP is the exact hash-pinned rc7 archive, including the original eleven
real board-build records. Native sanitizer and encrypted addressed graph checks run
again; Windows regressions, frozen icon/UI checks, source sanitation, exact provenance
and downloaded-asset checksum verification gate this new release. Evidence and SHA-256
manifests accompany the installer, portable package, source and firmware.

This remains a **prerelease**: physical RF, stopping, RC takeover, auxiliary OFF,
measured fleet capacity and real installed/display-scaling acceptance remain pending.
No automatic reconnect, arm, start or resume was introduced. Unknown command results
require deliberate recovery; HOLD does not guarantee accessory OFF.

Rollback: retain v1.2.0rc7 with its identical firmware pairing. The designated
mission-planning base remains v1.2.0rc6. Earlier stable and candidate assets are preserved.
