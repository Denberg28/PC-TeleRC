# PC TeleRC v1.0.0 ecosystem baseline — prerelease

This tag identifies the aligned v1.0.0 ecosystem baseline. The Windows package
retains internal version 1.0.0rc1/1.0.0.1 and mission firmware stays 0.2.0rc1.
It is an industrial development baseline, not a stable or field-qualified fleet product.

Publication requires the native Windows builder, application tests, fresh frozen
UI/media checks, portable and installer packaging, publish tests, mission security
regressions and all four actual board example builds to pass from this exact source.
A failed/pre-runner workflow must not publish an executable or claim success.

The prior candidate passed 283 application tests, 8 mission Python tests,
13 publish tests, 13 native mission/sanitizer profiles and 23 source UI/media checks.
Native Windows/frozen qualification remains blocked until the release workflow succeeds.
Physical qualification remains NOT TESTED even after software builds pass.

This version supports separate offline plans for rover IDs 1–20 and one active
addressed mission radio session. Simultaneous fleet monitoring, dynamic mesh routing
and 20-rover radio capacity are unimplemented/unvalidated. ArduRover executes local
missions and its configured failsafe policy remains authoritative.

The bundled four radio example binaries are keyless with RF disabled. Generate
and privately compile the matching BASE/ROVER/NODE set before deployment.
Do not distribute provisioned keys. Select the declared T3S3 SX1262 board profile.
Preserve NVS, private provisioning, FC parameters and settings for rollback.

Physical ELRS takeover, emergency stopping latency, controller mapping, power,
auxiliary OFF behavior, mission continuity and field RF remain unverified.
No LoRa safety packet is guaranteed to arrive. Use the restrained commissioning
procedure and independent local cutoff. See START_HERE.md and compatibility notes.

This release follows the reviewed mission development line. The independently
maintained default-branch manual firmware catalog/transport is preserved.
