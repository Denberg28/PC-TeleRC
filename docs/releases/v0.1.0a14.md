# PC TeleRC v0.1.0a14 — Native LoRa and dropdown UI

Adds native USB control of the TeleRC v0.8.53 LilyGO T3-S3 BASE, paired with its ROVER and dedicated ESP32-S3 motor controller. The wheel-to-LoRa path runs inside PC TeleRC; no relay script is needed. Wi-Fi and experimental ELRS modes remain available.

The compact interface has dropdown pages: Drive, Link Setup, Controller and LoRa Setup. STOP stays visible. Steering and drive sensitivity remain separate. LoRa Setup reads board role/status/counters and provisions inactive boards with a masked random pairing key; keys remain in memory only. Active radios cannot be re-paired, exchanges are serialized and timeout requires reopening USB.

LoRa driving requires an active BASE, a fresh rover heartbeat, CH1 steering/CH2 drive, centered wheel and neutral pedals. Enable PC Control explicitly, wait for DIRECT, then ARM explicitly. Navigation/configuration changes, stale input/link, failed writes and disconnect leave control OFF. No automatic arming, reconnect control, source switching or command retry.

## Validation
110 automated tests passed locally before the Windows build, plus compileall and dependency integrity. Includes framed USB CRC/resynchronization/expiry, role and inactive-board rejection, setup precision/state/timeout, no stored credentials, wheel drive/ARM/release/disconnect/reconnect, dropdown visibility and stop on navigation, and existing Wi-Fi/ELRS regressions. Windows CI repeats all tests and packages the executable and installer.

## Hardware gate
This is an unsigned private-testing candidate. Physical PXN/USB/radio/motor HIL, measured stop latency, RF range, installed-device upgrade and selector/transmitter takeover are NOT TESTED. Test with wheels lifted before driving. Setup guide: docs/LORA.md. Compatible firmware is TeleRC v0.8.53; this PC build does not modify Android or firmware.
