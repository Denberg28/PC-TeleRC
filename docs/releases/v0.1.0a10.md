# PC TeleRC v0.1.0a10 — Android-Aligned Rover Mapping

This maintenance prerelease aligns the Windows controller channel defaults with Android TeleRC.

## Change
- Steering remains **CH1**.
- Drive/throttle changes from **CH3** to **CH2**.
- This matches Android TeleRC's `RoverControls.channels(steering, drive)` behavior.

## Migration
- Existing installations using the untouched legacy **CH1 steering / CH3 throttle** default are migrated once to **CH1 / CH2**.
- Custom mappings are preserved.
- A current settings file explicitly using CH1/CH3 after migration remains valid and will not be repeatedly rewritten.

## Safety
No change to:
- PC Control enable prerequisites.
- MAVLink 1 bridge-control compatibility.
- controller/heartbeat watchdogs.
- neutral/release behavior.
- ARM/DISARM behavior.
- CH5-CH8 bridge protection.

## Bench check
With wheels lifted:
1. Install v0.1.0a10.
2. Confirm Safety & Control shows Steering RC channel 1 and Throttle RC channel 2.
3. Enable PC Control.
4. Turn the wheel and confirm CH1 changes.
5. Press the accelerator and confirm CH2 changes.
6. Verify ArduRover responds before lowering the vehicle.
