# PC TeleRC v1.1.0rc1 — firmware baseline support

Windows application update for the TeleRC ArduRover 1.1.0rc1 baseline: scalable
LoRa 0.4.0rc1 with the unchanged ESP32-S3 PWM converter 1.0.5.

- Detects scalable/unified/legacy mission firmware without confusing the TM2
  USB API version with the board version; rejects ambiguous/unsupported replies.
- Route loss/change, RF failure and queue loss clear mission verification and
  close an established session. Reconnect and re-upload deliberately; no replay.
- Retries a missed manual BASE identification query within the existing timeout.
- Shows the detected firmware and the manual rover-1 / mission rover-1–20 limits.
- Includes the exact hash-verified public baseline, its board-build evidence and
  setup guide. Existing private pairing keys and firmware remain unchanged.

One active addressed rover at a time. Windows source, protocol, frozen executable
and package checks gate publication. This is a release candidate; physical RF,
motor and takeover qualification is pending. PC TeleRC v1.0.1 remains available
as the previous stable software release. The application is unsigned.
