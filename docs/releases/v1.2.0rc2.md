# PC TeleRC v1.2.0rc2 — fleet map and route workflow

The fleet map now paints its terrain and overlays in one opaque, buffered frame.
Idle fleet refreshes no longer repaint the full map ten times a second, and the
bounded tile cache retains enough tiles for larger viewports. Splitter dragging
previews its final size, preserving the view and route during layout changes.

Upper-right Add rover and Remove rover buttons replace the number selector.
Add uses the lowest unused ID and restores its saved draft. Remove affects only
a disconnected, idle rover, saves its draft first and ignores late events from
its retired session. The last roster entry is retained.

Import route and Export route remain visible at the top of the selected mission
panel. Import validates WPL before changing the offline draft, rechecks session
state after the file picker, and updates the shared map. Export replaces files
atomically. Compact padding, two-row map tools and bounded vertical scrolling
keep controls accessible at smaller window sizes and with output settings open.

This application-only candidate retains fleet firmware 0.5.0rc1, compatible TU2
nodes and PWM converter 1.0.5 byte for byte. Existing private pairing sketches
remain valid; no firmware re-upload is required for these UI changes. Public
examples remain RF OFF. The v1.2.0rc1 mission-planning baseline is preserved.

Windows source regressions, frozen executable checks, public archive sanitation
and downloaded checksums gate publication. Physical RF, motor, FC operation and
RC takeover qualification remain pending. The Windows app is unsigned.
