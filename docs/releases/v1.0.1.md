# PC TeleRC v1.0.1

Stable Windows software release with the revised FPV cockpit, green power icon,
WIFI/LORA selectors, Steering Wheel/Keyboard controls, WASD and arrow-key support,
transparent telemetry, cleaner spacing and map loading before GPS.

Includes an installer, portable app, source, manual LoRa v1.0.1 BASE/ROVER/NODE1/
NODE2 firmware, matching mission sketches, fresh board images, checksums and build
evidence. Prior releases remain available for rollback.

Mission planning supports offline plans for IDs 1–20 and one active addressed
mission session, verified upload/readback, explicit Start and HOLD. It requires
the separate **TM2 mission 0.2.0rc1** firmware and private matching provisioning.
Public mission examples have RF OFF. Manual LoRa v1.0.1 cannot execute missions.
Read FIRMWARE-COMPATIBILITY.md before flashing.

Stable describes the desktop software release channel. Physical RF, power/stall,
stop timing, accessory OFF and handset-takeover qualification remain unrecorded;
the mission firmware retains its rc1 designation. This is not a field-qualified
fleet-system claim. WiFi MAVLink is not end-to-end authenticated. Windows binaries
are unsigned. Complete restrained commissioning before vehicle operation.

New separate firmware images preserve NVS at the listed offsets without erase.
The original manual ZIP also contains factory images that erase all flash/NVS;
use its flashing guide and back up existing configuration first.
