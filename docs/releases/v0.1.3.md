# PC TeleRC v0.1.3 — offline maps and working LoRa setup

Stable release requested after the user confirmed PC → BASE → LoRa → ROVER → SpeedyBee operation with the 915 MHz preset and PC TeleRC v0.1.2. The new offline-map features have automated and frozen Windows validation; long-duration field operation and RF range remain hardware validation items.

- Open raster MBTiles (PNG/JPEG/WebP) for offline map coverage. Browse by dragging, zoom, and use ◎ to resume following rover GPS. Restore the last view after restart; missing coverage is clearly labeled.
- Keep previously viewed online tiles available with online maps switched off, including older cached tiles. No geographic map is bundled. Vector MBTiles and Android MapLibre offline databases are not supported by the native PC map renderer.
- Minimize the lower-left map to a compact Map button and restore it at the same corner. The preference persists across restarts.
- Include the LoRa/USB fixes: 8–32 visible ASCII password characters, sanitized serial errors, retained setup-port ownership on failed close, and cancelled reconnect callbacks. The compiled telerc123 preset needs no Save to board operation.
- Include the exact user-confirmed direct 915 MHz, telerc123, zero-relay BASE/ROVER source preset plus target builds compiled from those packaged sources. Existing working boards need no reflash for this application update.

Keep camera, GPS display and map browsing independent of driving. Preserve explicit ARM, manual control enable, keyboard-focus stops, neutral acquisition, radio/controller stale stops and transmitter takeover. No watchdog thresholds changed.

Downloads: Windows installer, portable ZIP, source ZIP, 915 MHz preset sketches/target builds, SHA256 checksums and frozen Windows UI/media/offline-map verification report. Previous stable releases remain available.
