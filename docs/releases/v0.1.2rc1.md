# PC TeleRC v0.1.2rc1 — LilyGO runtime setup candidate

LilyGO T3-S3 firmware 0.4.0 adds a BOOT/OLED menu: hold to enter, tap to move and hold to select. ROVER saves Wi-Fi or LoRa without reflashing. BASE remains USB-to-LoRa; both roles offer a local setup page and status screen.

Configure the same eight-character LoRa password/frequency on both boards using Link Settings or PC LoRa Setup. Existing advanced hex keys remain supported. Entering setup pauses the link, retries pending neutral/release writes and delays restart until the previous PC session times out. Control requires manual enable at neutral afterwards.

Retains independent sensitivities, PWM converter 1.0.5, bridge 0.1.5, 500 ms link watchdogs, receiver takeover and explicit ARM. See LILYGO-RUNTIME-SETUP.md in the firmware package. This is an unpromoted test candidate; v0.1.1 remains the latest stable release. Physical rover validation remains outstanding.
