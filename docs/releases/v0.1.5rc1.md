# PC TeleRC v0.1.5rc1 — addressed LoRa mission planning

Adds a map mission editor with ordered waypoints, F1/F2/F3 ON/OFF events, WPL
import/export, and a dedicated connection for TeleRC LoRa Mission v0.1.0 firmware.
Rover IDs 1–20 are locked per session; the manual radio path stays separate.

Upload requires disarmed MANUAL/HOLD, verified FC loss parameters, accepted upload
and full actionable readback comparison. START requires a separate exact target/
digest confirmation, repeated readback, fresh GPS/stationary telemetry and explicit
RC arming. START is sent once and never replayed; lost confirmation is UNKNOWN.
HOLD cancels pending work and requires a fresh FC HOLD heartbeat. USB failure,
telemetry loss, GUI stall or closing clears readiness and stops the mission link.

Auxiliary outputs are opt-in, checked against dedicated FC output settings, and
have planned initial/final OFF rows. HOLD/loss cannot guarantee auxiliary OFF;
independent cutoff is required. This is onboard AUTO mission timing, unlike the
phone's stationary Guided function sequence. See docs/MISSION-PLANNING.md.

Development candidate: host tests and protocol peers are not RF, physical hardware,
ArduRover SITL or Windows qualification. Windows packages are staged as draft only
after regression and frozen UI/media/mission checks. Do not replace stable before
restrained-wheel, RC takeover, measured loss/stop and accessory cutoff acceptance.
