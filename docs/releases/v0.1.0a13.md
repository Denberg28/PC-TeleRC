# PC TeleRC v0.1.0a13 — Independent Sensitivity and Experimental ELRS

## Features
- Separate steering and drive sensitivity sliders, each 25–100%, with labels below and saved values. Existing settings default drive sensitivity to 100%.
- Drive scales forward/reverse independently and then applies the throttle limit. Low gain cannot hide a pressed pedal from ARM/enable neutral checks.
- Experimental ELRS external TX USB MAVLink connection: enter the module COM port and Apply & Reconnect. Fixed 460800 baud, DTR/RTS low, bounded serial I/O and 5 Hz PC RC overrides.
- Preserve the TeleRC ESP32 Wi-Fi path, manual enable, accepted vehicle identity, fresh input/heartbeat checks, and owned neutral/release. No bridge ASCII discovery/disconnect is sent to ELRS serial.

## Downloads
PC-TeleRC-Setup-v0.1.0a13.exe is the Windows x64 installer. PC-TeleRC-portable-v0.1.0a13.zip must be fully extracted. Matching SHA256 files accompany both.

## ELRS hardware status
The intended setup is HGLRC T ONE 915 MHz external module on a RadioMaster Pocket and GEPRC ELRS DUAL 915M PA500 RX. Exact firmware and USB MAVLink capability remain unverified. This release does not support raw CRSF module-bay input or guarantee simultaneous Pocket/PC arbitration or takeover. Verify that the T ONE exposes a MAVLink-capable COM port. A normal CRSF receiver configuration does not enable this USB path automatically.

For initial PC wheel testing, use the documented ELRS standalone USB MAVLink configuration, compatible TX/RX firmware and a suitable MAVLink FC UART. Existing firmware, wiring and parameters are not changed. See docs/ELRS.md for the hardware gate, official sources, bandwidth and safety limits. Low-rate 900 MHz modes may not sustain wheel-control traffic; start with a suitable tested radio rate and low telemetry load.

## Validation
94 automated tests pass locally, including independent slider persistence/runtime scaling, unscaled neutral checks, serial heartbeat bootstrap, drive/release, pre-open DTR/RTS configuration, write backpressure and missing-port failure. Release CI repeats Windows tests, dependency/syntax checks and executable/installer packaging.

ELRS is experimental and has not been tested on the named hardware pair. USB write success does not confirm over-air delivery. Bench-check latency, stale commands, stop behavior and control-source handover with wheels lifted. The Windows installer is unsigned.
